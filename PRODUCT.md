# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

- Static HTML/CSS + minimal vanilla JavaScript (vanilla).
- No build step; deployed to GitHub Pages (`Dali-dev05.github.io`).
- Greenfield option recorded for future migration.

## Users

- **Primary:** employers, recruiters and collaborators evaluating **Dali Muñoz Moreno** as a developer candidate or partner. The job to be done is to assess experience, technical capability and communication quickly, during a high-stakes decision.
- **Secondary:** visitors and recruiters browsing a personal portfolio of real projects; curious users arriving from search or referrals.

## Product Purpose

Dali Muñoz Moreno's personal page presents a professional CV and a curated set of projects in one clear, trustworthy surface, so recruiters and collaborators quickly understand what has been built, with what, and how to reach out.

**Success =** a reader can, within seconds, identify who the author is, what has been built, and how to contact him.

## Positioning

For employers evaluating a software developer's practical full-stack output, Dali Muñoz Moreno's personal page presents verifiable credentials and real projects — clean, readable and honest — rather than a generic template dashboard.

## Operating Context

- The page is authored and maintained in GitHub; the deployment target is GitHub Pages.
- Content is in **Spanish** (primary); bilingual expansion is possible in the future.
- The author edits HTML/CSS and commits; there is no CMS or headless backend.
- Personal project; single deploy; no authentication or paywall.

## Capabilities and Constraints

- **Capabilities:** static HTML/CSS/JS; GitHub Pages hosting; Git version control; a personal portfolio of CV, skills and projects.
- **Projects already represented:** *Harmands Motors* (Flutter, e-commerce for motorcycle spare parts); C#/dotnet web app for control and management of internet providers (practicas profesionales).
- **Technical constraints:** no build toolchain today; no custom domain; public GitHub Pages; no authentication.
- **Undecided:** bilingual expansion (ES → EN), contact form backend, analytics.

## Brand Commitments

- Voice: professional, clear, direct; Spanish language.
- Visual direction (explicit request): **Vercel-inspired** — clean, modern, minimal, confident; strong typography; subtle depth; restrained blue/purple accents.
- The impeccable craft floor is applied on top of the Vercel direction: saturation and decorative effects are earned, not default.

## Evidence on Hand

- Repository files: `index.html`, `styles.css`, `README.md`, `.hermes/skills/impeccable/`.
- Existing content: CV/profile copy, skills list, and two projects.
- The user's profile and activity: programming, teaching and video games.

## Product Principles

1. **Make the work legible:** recruiters find what they need within seconds.
2. **Build in the open:** clean, readable code that reflects the quality of the displayed work.
3. **Substance over ornament:** real projects and real skills; the work carries the page.
4. **Ship minimal and coherent:** every section earns its place.
5. **Easy to maintain:** the page stays simple enough for the author to keep editing.

## Accessibility & Inclusion

- WCAG AA contrast (body ≥4.5:1, large text ≥3:1); never gray on color.
- Semantic HTML: headings, landmarks, focus states, keyboard navigation.
- Text scaling and readable line length (measure 65–75ch).
- Language declared as Spanish (`lang="es"`), with opt-in to English later.
